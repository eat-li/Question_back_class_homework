## 2. 后端接口契约（真实，源自 `server/src`）

### 2.1 基础约定

- **Base URL**：`http://<电脑局域网IP>:3000/api`（开发期）。示例：`http://192.168.1.100:3000/api`。
- **CORS**：后端 `app.use(cors())` 默认允许所有来源，开发联调无需额外配置。
- **响应包络**：成功 `code:0`，失败 `code≠0`（如作业不存在返回 `40400`）。`utils/request.js` 统一对 `code` 解包。
- **微信域名白名单**：`manifest` 中 `urlCheck:false` **仅对开发期工具生效**。正式提审 / 上线前，必须在
  **微信公众平台 → 开发 → 开发管理 → 服务器域名** 中配置：
  - request 合法域名：`http://<IP>:3000`（生产建议用域名 + https）
  - downloadFile / uploadFile 合法域名：`https://<OSS_BUCKET>.<OSS_REGION>.aliyuncs.com`（即后端 `OSS_BASE_URL` 对应的 host）

### 2.2 接口清单

| 方法   | 路径                           | 说明                         | 关键参数 / 返回                                                                                   |
| ------ | ------------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------- |
| GET    | `/api/homeworks`               | 作业列表（全部，按 id 倒序） | 返回 `Homework[]`；**未过滤 status**                                                              |
| POST   | `/api/homeworks`               | 新建作业（后台用）           | body 见 §2.3；返回创建对象                                                                        |
| GET    | `/api/homeworks/:id`           | 作业详情（含成绩与学生）     | 含 `submissions[].student`                                                                        |
| GET    | `/api/homeworks/:id/questions` | 该作业题目详情（按布置顺序） | 返回 `Question[]`（导出 / 查看用）                                                                |
| PATCH  | `/api/homeworks/:id`           | 更新作业                     | body 同新建                                                                                       |
| DELETE | `/api/homeworks/:id`           | 删除作业                     | —                                                                                                 |
| PUT    | `/api/homeworks/:id/scores`    | 录入成绩（后台用）           | `{ scores: [{studentId, score}] }`                                                                |
| POST   | `/api/upload`                  | 上传文件到 OSS               | `multipart/form-data`，字段名 `file`；**仅支持 jpg/png/gif/webp 图片**，10MB；返回 `{ url, key }` |
| GET    | `/api/health`                  | 健康检查                     | `{ code:0, data:{status:'up'} }`                                                                  |

### 2.3 数据模型映射

**Homework**（`server/src/models/Homework.js`）

| 字段                | 类型     | 说明                                |
| ------------------- | -------- | ----------------------------------- |
| `id`                | number   | 主键                                |
| `title`             | string   | 作业标题                            |
| `questionIds`       | JSON[]   | 题目 id 数组（布置顺序即数组顺序）  |
| `studentIds`        | JSON[]   | 下发学生 id 数组                    |
| `startAt` / `endAt` | datetime | 起止时间                            |
| `status`            | enum     | `draft` / `published` / `closed`    |
| `remark`            | text     | 备注                                |
| ⚠️ `attachments`    | —        | **当前模型无此字段**，文件下发见 §6 |

**Question**（`server/src/models/Question.js`）——题目详情接口返回

| 字段           | 类型       | 说明                                |
| -------------- | ---------- | ----------------------------------- |
| `id`           | number     | 主键                                |
| `title`        | text(HTML) | 题干（富文本，图片为 OSS 绝对 URL） |
| `type`         | enum       | `choice` / `fill` / `solve`         |
| `difficulty`   | int(1-5)   | 难度                                |
| `knowledgeTag` | string     | 知识点标签                          |
| `body`         | text       | 补充说明（富文本 / LaTeX）          |
| `options`      | JSON       | 客观题选项                          |
| `answer`       | text(HTML) | 答案与解析（含图片）                |

```js
export default config
```

### 3.2 `wxapp/utils/request.js`

```js
import config from '@/config'

function request({ url, method = 'GET', data }) {
  return new Promise((resolve, reject) => {
    uni.request({
      url: config.API_BASE + url,
      method,
      data,
      header: { 'content-type': 'application/json' },
      success: (res) => {
        const body = res.data
        if (body && body.code === 0) return resolve(body.data)
        reject(new Error(body?.message || '请求失败'))
      },
      fail: (err) => reject(err)
    })
  })
}

export default {
  get: (url, data) => request({ url, method: 'GET', data }),
  post: (url, data) => request({ url, method: 'POST', data }),
  patch: (url, data) => request({ url, method: 'PATCH', data }),
  del: (url) => request({ url, method: 'DELETE' })
}
```

> `@` 别名在经典 uni-app 中指向项目根目录（即 `manifest.json` 所在目录）。

### 3.3 `wxapp/api/homework.js`

```js
import request from '@/utils/request'

export default {
  list: () => request.get('/homeworks'),
  detail: (id) => request.get(`/homeworks/${id}`),
  questions: (id) => request.get(`/homeworks/${id}/questions`)
}
```

## 4. 页面规划

### 4.1 作业列表页 `pages/index/index.vue`（改造现有）

- 进入即拉取 `GET /api/homeworks`，**前端过滤 `status === 'published'`**（后端暂不按状态过滤，见 §6）。
- 卡片展示：标题、状态、截止时间、题目数量（`questionIds.length`）。
- 点击卡片 → `uni.navigateTo` 到 `pages/homework/detail?id=xxx`。

```vue
<template>
  <view class="list">
    <view v-for="hw in list" :key="hw.id" class="card" @tap="open(hw.id)">
      <text class="title">{{ hw.title }}</text>
      <text class="meta"
        >已发布 · 截止 {{ fmt(hw.endAt) }} · {{ (hw.questionIds || []).length }} 题</text
      >
    </view>
    <view v-if="!list.length" class="empty">暂无已发布作业</view>
  </view>
</template>

<script>
import api from '@/api/homework'
export default {
  data() {
    return { list: [] }
  },
  onLoad() {
    this.load()
  },
  methods: {
    async load() {
      try {
        const all = await api.list()
        this.list = (all || []).filter((h) => h.status === 'published')
      } catch (e) {
        uni.showToast({ title: e.message || '加载失败', icon: 'none' })
      }
    },
    open(id) {
      uni.navigateTo({ url: `/pages/homework/detail?id=${id}` })
    },
    fmt(d) {
      return d ? String(d).slice(0, 10) : '—'
    }
  }
}
</script>
```

### 4.2 作业详情 / 题目页 `pages/homework/detail.vue`（新增）

- `onLoad(options.id)` → 并行请求 `detail(id)` 与 `questions(id)`。
- 题目列表用 `<rich-text :nodes="q.title">` 渲染题干 HTML（OSS 图片可直接显示）。
- 若有附件（`attachments`，见 §6 改造后）→ 列出附件，点击走下载逻辑（§5.3）。
- 难度 / 题型 / 知识点用标签展示。

```vue
<template>
  <view class="detail">
    <view class="head">
      <text class="h-title">{{ homework.title }}</text>
      <text class="h-meta">截止 {{ fmt(homework.endAt) }}</text>
    </view>

    <view class="sec">题目（{{ questions.length }}）</view>
    <view v-for="(q, i) in questions" :key="q.id" class="q">
      <text class="q-no">第 {{ i + 1 }} 题</text>
      <rich-text :nodes="q.title"></rich-text>
      <view class="tags">
        <text class="tag">{{ typeText(q.type) }}</text>
        <text class="tag">难度 {{ q.difficulty }}</text>
        <text v-if="q.knowledgeTag" class="tag">{{ q.knowledgeTag }}</text>
      </view>
    </view>

    <view v-if="attachments.length" class="sec">附件</view>
    <view v-for="(a, i) in attachments" :key="i" class="file" @tap="download(a)">
      <text>{{ a.name || '附件' + (i + 1) }}</text>
      <text class="dl">下载</text>
    </view>
  </view>
</template>

<script>
import api from '@/api/homework'
export default {
  data() {
    return { homework: {}, questions: [], attachments: [] }
  },
  onLoad(opt) {
    if (opt.id) this.load(opt.id)
  },
  methods: {
    async load(id) {
      try {
        const [hw, qs] = await Promise.all([api.detail(id), api.questions(id)])
        this.homework = hw || {}
        this.questions = qs || []
        this.attachments = (hw && hw.attachments) || [] // 改造后才有
      } catch (e) {
        uni.showToast({ title: e.message || '加载失败', icon: 'none' })
      }
    },
    download(a) {
      /* 见 §5.3 */
    },
    typeText(t) {
      return { choice: '选择题', fill: '填空题', solve: '解答题' }[t] || t
    },
    fmt(d) {
      return d ? String(d).slice(0, 10) : '—'
    }
  }
}
</script>
```

## 5. 关键代码范式

### 5.1 请求封装

见 §3.2 `utils/request.js`：统一 `BASE_URL` + 解包 `{code,message,data}`，业务层只拿 `data`。

### 5.2 富文本渲染（题目 / 答案）

小程序用内置 `<rich-text :nodes="html">` 渲染 HTML 字符串。

- ✅ OSS 绝对路径图片可正常显示。
- ⚠️ **KaTeX 公式**：Web 端用 KaTeX 把公式渲染成 HTML span，这些 span 依赖 KaTeX 的 CSS / 字体，**小程序 `<rich-text>` 不会加载外部样式表**，公式大概率显示异常。解决方式见 §6「富文本 / KaTeX 限制」。

### 5.3 文件下载（附件模式，需 §6 改造后生效）

```js
download(file) {
  uni.showLoading({ title: '下载中' })
  uni.downloadFile({
    url: file.url,                 // OSS 公开地址，host 需加入微信 downloadFile 白名单
    success: (res) => {
      uni.hideLoading()
      if (res.statusCode === 200) {
        uni.openDocument({
          filePath: res.tempFilePath,
          showMenu: true,           // 允许右上角转发 / 保存
          fail: () => uni.showToast({ title: '该格式无法预览', icon: 'none' })
        })
      }
    },
    fail: () => { uni.hideLoading(); uni.showToast({ title: '下载失败', icon: 'none' }) }
  })
}
```

### 5.4 图片上传（仅当小程序内需要发图时）

复用后端 `POST /api/upload`（字段 `file`，仅图片）。小程序选图：

```js
uni.chooseMedia({
  count: 1,
  success: async (res) => {
    const filePath = res.tempFiles[0].tempFilePath
    uni.uploadFile({
      url: config.API_BASE + '/upload',
      filePath,
      name: 'file',
      success: (up) => {
        const data = JSON.parse(up.data)
        if (data.code === 0) console.log('OSS url:', data.data.url)
      }
    })
  }
})
```

## 6. 已知缺口与需后端配合的改造

小程序"发布 + 下载"目前受后端现状限制，以下是阻塞项与建议改法（**本期小程序端不实现发布，仅列改造点供后续排期**）：

| #   | 缺口                                             | 影响                                              | 建议改造（后端）                                                                                               |
| --- | ------------------------------------------------ | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 1   | `Homework` 模型**无 `attachments` 字段**         | 无法存储可下载的习题 PDF / Word                   | 模型加 `attachments: { type: JSON }`，存 `[{ name, url, key }]` 数组                                           |
| 2   | `/api/upload` **仅支持图片**（jpg/png/gif/webp） | 无法上传习题附件                                  | 新增 `/api/upload/file` 或放宽 mimetype，支持 `application/pdf`、`doc`、`docx` 等；OSS key 目录改 `homeworks/` |
| 3   | `GET /api/homeworks` **不按 status 过滤**        | 小程序会拉到草稿 / 已关闭作业                     | 支持 `?status=published` 查询参数；或小程序端自行过滤（已在前端兜底）                                          |
| 4   | 小程序**无身份 / 鉴权**                          | 所有人可见全部已发布作业；`studentIds` 未用于隔离 | 单用户自用可接受"全量可见"；如需按学生隔离需引入 openid→student 绑定（超出本期）                               |
| 5   | **KaTeX 公式**在 `<rich-text>` 不渲染            | 含公式题目显示异常                                | 题库录入时公式尽量以**图片**存储（OSS URL）；或在题目 `body`/`answer` 中同时提供图片版                         |

> 第 1、2 项实现后，`detail.vue` 的 `attachments` 与 §5.3 下载逻辑方可生效。

## 7. 运行 / 调试 / 发布

1. **准备后端**：启动 `server`（`PORT=3000`，确保 `OSS_*` 环境变量已配），浏览器访问 `http://<IP>:3000/api/health` 验证。
2. **填 IP**：把 `wxapp/config.js` 的 `API_BASE` 改成电脑局域网 IP。
3. **HBuilderX 导入**：文件 → 导入 → 从本地目录，选 `wxapp/`。
4. **运行**：运行 → 运行到小程序模拟器 → 微信开发者工具。首次会提示用微信扫码 / 填 `AppID`（测试号可空，正式需自有 AppID）。
5. **联调**：因 `urlCheck:false`，开发期用局域网 IP 可直接请求；真机预览同样走局域网。
6. **上线前**：在微信公众平台配置 request / downloadFile / uploadFile 合法域名（生产建议 HTTPS 域名 + OSS 自定义域名）。
