# 数学题库（小程序端）

> 技术栈：uni-app（Vue 3）→ 微信小程序（mp-weixin）
> 当前进度：**题库浏览已完成**，可分享单题；后续功能按 `docs/小程序架构设计.md` 逐块加。

## 已实现

**题库列表**（`pages/bank/list`，启动页）
- 输入即搜（300ms 防抖）+ 搜索历史（本地留存 8 条）
- 题型筛选（全部 / 选择 / 填空 / 解答）、难度筛选（1–5 星）
- **知识点视图**：按知识点汇总题量与题型分布，一级/二级知识点点击直达筛选
- 分页加载（触底 + 手动加载更多）、下拉刷新、空态/错误态/重试
- 知识点数据本地缓存 5 分钟，二次进入几乎秒开

**单题详情**（`pages/bank/detail`，分享落地页）
- 题干、选项、补充说明、答案与解析（默认折叠，点击展开）
- 上一题 / 下一题（沿用列表页的 id 序列，返回列表不丢滚动位置）
- **分享到会话/群、朋友圈**：标题自动生成为「知识点｜题干前 24 字」
- 冷启动直达：从群里点开分享链接可直接看题，无登录墙
- 「查看原题图」收集题干与解析里的图片，支持双指放大

## 安全模型

小程序一律使用**只读访客令牌**（`POST /api/auth/guest`），只能访问 `/api/open/*`，
而该路由组在服务端中间件层强制只允许 GET/HEAD。

> 旧版本把管理员账号密码写进了小程序包，那是上线前必须拔掉的雷，已移除。

## 目录结构

```
wxapp/
├── config/index.js          # 环境配置（dev/prod 切换）+ 分页/缓存参数
├── utils/
│   ├── request.js           # 访客令牌 + 401 重签 + 解包
│   ├── richtext.js          # 富文本清洗：图片自适应 / 公式降级 / 纯文本提取
│   ├── latex.js             # LaTeX → 可读文本（零依赖）
│   ├── storage.js           # 带 TTL 的本地缓存
│   └── constants.js         # 题型 / 难度 / 选项字母
├── api/question.js          # 题库只读接口
├── store/index.js           # 列表上下文 + 搜索历史
├── components/              # rich-block / question-card / empty-state
├── pages/bank/              # list.vue（列表）+ detail.vue（详情）
└── docs/小程序架构设计.md     # 架构、增长设计、上线 checklist
```

## 联调

1. 启动后端 `server`（`PORT=3000`）；
2. `config/index.js` 里 `API_BASE` 改成电脑的局域网 IP（`isProd` 保持 `false`）；
3. HBuilderX 导入 `wxapp/` → 运行 → 运行到小程序模拟器 → 微信开发者工具；
4. 开发期 `manifest.json` 已设 `urlCheck:false`，局域网 http 可直接联调。

## 上线前

按顺序做完 `docs/小程序架构设计.md` §10 的 checklist。
其中最容易被卡住的两项：

1. **服务类目资质**（教育类目通常需要机构资质，个人主体受限）——先去确认这个；
2. **downloadFile 合法域名要加 OSS 域名**，否则题目图片在真机上全部显示不出来。

## 已知限制

- 公式是降级渲染（LaTeX → 可读文本），不是真正的数学排版。
  全库 123 道题校验通过，但复杂矩阵、多行对齐公式会不好看。
  升级方向是引入 mp-html + katex 插件。
- rich-text 内的图片不能点击，详情页用「查看原题图」绕过。
- 所有访客看到同一份题库，暂未做按学生隔离。
